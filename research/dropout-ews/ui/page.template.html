Bayesian network · 25 nodes · two periods · Sri Lankan school context

A screen that points at the school, not at the child

The model estimates next-term disengagement risk from household, school-environment and prior-term evidence. Its central commitment is structural: no path runs from a student's neurotype to the outcome except through something a school can change. Testing that commitment is what turned up the findings below — including one that says the network, as specified, can barely see its own most important lever.

§1 C5 · Signal transmission

What happens to the accommodation signal on its way to the outcome

One student, one building, one change: school accommodation switched from inadequate to adequate. Each bar is how far that single change moves the adverse state of the next node along the chain. The question is what is left when it arrives.

Read the first route and the second together. Same chain, same parameters — the only difference is that the amended variant restores two edges the brief omits, and the signal arriving at the outcome grows sevenfold. Nothing about the accommodation effect changed; the model simply gained somewhere to put it.

The third route is the one that was missing. It carries 5.8× more signal at its final mediator than the attendance route does — 0.1648 at School_Engagement against 0.0286 at Current_Attendance — which reframes the diagnosis. The brief's error was not that its chain was too long. It was that distress reached the outcome only through attendance, the narrowest channel available, while the affective route to disengagement was left out entirely.

Reading the bars precisely: every hop except the last is specific to that route. The final value is marked ∑ because the outcome shift is a property of the whole model, not of one path through it — in the amended variant four directed paths connect these endpoints, so no single route can claim it. Conflating the two is what made the middle chart look like decay when it was really interference.

§8 · Causal semantics

Seeing a value is not setting it

Conditioning on School_Accommodation=Adequate asks about students who happen to attend accommodating schools. Intervening asks what happens if this school starts accommodating. Only the second is a policy question, and the two coincide only when the structure says they must.

The guardrail

Interventions are restricted to an allowlist of modifiable school and household factors. Asking the model what a child's risk would be if they were not autistic is a forbidden question, not a malformed one, so it is refused rather than answered.

        §9 · Sensitivity
        
How much of this survives being wrong about the parameters

        
Every parameter here was elicited, not estimated, so the only honest question is whether the conclusions are robust to getting them wrong. Each of the four most load-bearing assumptions was perturbed ±10% and all seven scenarios re-run.

      

      

      

      

    


    
    

      

        §11.1 · Deployment arithmetic
        
Who a threshold actually flags

        
This is the section that decides whether the model is safe to deploy, and it needs no external data — the model's own numbers are enough. Precision is capped by the base rate: no ranking, however good, can beat prevalence / flag rate.

      

      

      

        

        

        

        
Reading the ceiling columns. Each is min(1, prevalence / flag rate) — the best precision any ranking could achieve at that threshold if the true leaving rate were 1%, 2% or 5%. Not capped means the ratio exceeded 1, so the base rate imposes no limit there; it does not mean precision would be perfect. Nothing in these columns is a measurement — they are upper bounds implied by arithmetic, and the model has never been compared against a real outcome.

        §11 · Governance
        
The commitments are in the code, not the documentation

        
A promise in a report is not a constraint. Each of these is enforced at runtime and covered by a test that fails if someone removes it.

      

      
    
      
    
        
    Must never be used to
    
        
    Deny or restrict education · discipline, stream or exclude a student · rank schools or teachers · label a child in any permanent record · report families to police, labour or child-protection authorities automatically.
    
        
    Because most flagged students would not have left school anyway, every output must lead to an offer of support that costs the student nothing if the flag was wrong. That is not a nicety; it is the only posture the false-positive arithmetic permits.
    
      
    
    
    

    
    
    
      
    
        Appendix A · Review pass
        
    Six defects found by attacking our own work
    
        
    A self-review run as an adversarial probe of invariants the original suite did not cover. All six are fixed and regression-tested, 124 → 133 tests. Two of them changed a claim in the report, and one produced a new finding.
    
      
    
      
    
      
    
        
    Why the first 124 tests missed three of these. They checked the happy path of each function against itself, and the arithmetic was right, so nothing failed. What found D1, D2 and D5 was asking what a caller could do wrong, and what an invariant would look like if it were violated. D2 was the worst case: it was hiding behind a test that passed for the right reason on the wrong model.
    
        
    D3 is the general lesson. Any fact stated in two places will eventually disagree. The fix was not to proofread more carefully but to delete the second copy — evidence levels became data, and the report section is generated from them. This page is built the same way: its structure, edge narratives and numbers are extracted from the module and the report at build time, and the build fails if the two disagree.
    
      
    
    
    

    
    
      
    Status. The code runs, the tests pass, and the numbers are internally coherent. None of them are about Sri Lankan schools yet — the outcome node is not an observable event, so nothing here can currently be calibrated or falsified. That is the prerequisite for everything else.
