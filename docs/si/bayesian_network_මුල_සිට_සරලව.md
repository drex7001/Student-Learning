# Bayesian Network මුල සිට සරලව (Bayesian Networks from Scratch)

මෙම ලේඛනය මඟින් Bayesian Network (බේසියානු ජාල) යනු කුමක්ද යන්නත්, ශ්‍රී ලාංකීය පාසල් පූර්ව උපකාරක පද්ධතිය (School Early-Support System) සඳහා වෙනත් AI තාක්ෂණයක් වෙනුවට මෙයම තෝරාගැනීමට හේතුවත් සරලව පැහැදිලි කරයි.

---

## 1. Bayesian Network එකක් කියන්නේ මොකක්ද?

සරලවම කිව්වොත්, අනාගතයේ යම් දෙයක් සිදුවීමට ඇති **අවදානම හෝ සම්පාවිතාව (Probability)** ගණනය කිරීම සඳහා, ඊට බලපාන **හේතු සහ ඵල එකිනෙකට යා කර සාදාගත් ජාලයක් (Network)** Bayesian Network එකක් ලෙස හැඳින්වේ. 

මේක හරියට මකුළු දැලක් වගේ. එක තැනකින් ඇද්දොත් මුළු දැලම හෙල්ලෙනවා. ඒ වගේම එක හේතුවක් වෙනස් වුණොත්, අන්තිම ප්‍රතිඵලය වෙනස් වෙනවා.

### සරල උදාහරණයක් බලමු:
හිතන්න අද පන්තියේ ළමයෙක් නෑ කියලා. ඇයි ඒ ළමයා ආවේ නැත්තේ?
* සමහරවිට උණ හැදිලද?
* නැත්නම් බස් එකට දෙන්න සල්ලි නැති නිසාද?
* සල්ලි නැත්තේ ගෙදර ආර්ථික අපහසුතා නිසාද?

මෙතන තියෙන්නේ තනි හේතුවක් නෙවෙයි. එකකට එකක් බැඳුණු හේතු දාමයක්. 
> **දුප්පත්කම** ➡️ **බස් ගාස්තු නැතිකම** ➡️ **පාසල් නොපැමිණීම** ➡️ **පාසල අතහැරීම**

Bayesian Network එකක කරන්නේ අන්න ඒ වගේ **හේතු (Causes)** සහ **ප්‍රතිඵල (Effects)** ඊතලවලින් (Edges) යා කරලා රූප සටහනක් හදන එක. ඊට පස්සේ ඒ හැම ඊතලයකටම **සම්පාවිතාවක් (ප්‍රතිශතයක් - %)** දෙනවා. (උදාහරණයක් විදිහට: ආර්ථික අපහසුතා තියෙන පවුලක ළමයෙකුට ප්‍රවාහන ප්‍රශ්න එන්න තියෙන සම්පාවිතාව 80%යි).

මේ විදිහට මුළු ජාලයම ගණනය කළාම, ළමයෙකුගේ අනාගත අවදානම ඉතා නිවැරදිව කියන්න පුළුවන්.

## 2. ඇයි අපි මේ Project එකට Bayesian Network එකක්ම තෝරාගත්තේ?

අද කාලයේ AI කිව්ව ගමන් හැමෝටම මතක් වෙන්නේ **Neural Networks (Deep Learning)**, **Machine Learning** වගේ දේවල්. එහෙනම් ඇයි අපි ළමයින්ගේ අවදානම මනින්න ඒ වගේ ජනප්‍රිය තාක්ෂණයක් පාවිච්චි නොකර, අමාරු ගණිතයක් තියෙන Bayesian Network එකක් තෝරාගත්තේ? ඒකට ප්‍රධාන හේතු 3ක් තියෙනවා.

### හේතුව 1: පැහැදිලි කළ හැකි වීම (Explainability / No Black Box)

ඔබ සාමාන්‍ය Machine Learning (උදා: Neural Network) මොඩල් එකකට ළමයෙකුගේ දත්ත ටික දුන්නාම, ඒක එකපාරටම කියනවා *"මේ ළමයා පාසල අතහැරලා යන්න තියෙන අවදානම 90%යි"* කියලා. හැබැයි ගුරුවරයෙක් **"ඇයි ඔයා එහෙම කියන්නේ?"** කියලා ඇහුවොත්, ඒ මොඩල් එකට ඒක පැහැදිලි කරන්න බෑ. ඒක හරියට "Black Box" එකක් වගේ. ඇතුළේ වෙන දේ අපි දන්නේ නෑ.

නමුත් Bayesian Network එකක හැම හේතුවක්ම ඊතල වලින් යා කරලා තියෙන නිසා, පද්ධතියට පුළුවන් ගුරුවරයාට පැහැදිලිවම කියන්න: *"ගුරුතුමනි, ළමයාගේ අවදානම වැඩි වෙන්න ප්‍රධාන හේතුව ළමයාගේ මානසික පීඩනයයි, ඒ මානසික පීඩනයට හේතුව පාසලේ වැසිකිළි/ජල පහසුකම් අඩු වීමයි"*. මේ විදිහට **ප්‍රශ්නයේ මුලටම (Root Cause)** යන්න Bayesian Network එකට පුළුවන්.

### හේතුව 2: සක්‍රීය මැදිහත්වීම් මැනිය හැකි වීම (`do()` Calculus / Interventions)

සාමාන්‍ය AI මොඩල් එකකට පුළුවන් **නිරීක්ෂණය (Observation)** කරන්න විතරයි. (උදා: "බස් එකේ එන්න විදිහක් නැති ළමයි ගොඩක් වෙලාවට ඉස්කෝලේ එන්නේ නෑ"). ඒක නිකන්ම Correlation එකක් විතරයි.

හැබැයි Bayesian Network එකක තියෙන විශේෂම හැකියාව තමයි **Causal Inference (හේතු-ඵල න්‍යාය)**. ඒ හරහා අපිට **`do()` (මැදිහත්වීම)** කියන ගණිතමය ක්‍රමය පාවිච්චි කරන්න පුළුවන්. 
* පද්ධතියට පුළුවන් මෙහෙම අනුමාන කරන්න: *"හරි, අපි නිකන්ම බලන් ඉන්නේ නැතුව, ළමයාට නොමිලේ පාසල් බස් රථයක් දුන්නොත් මොකද වෙන්නේ? (ඒ කියන්නේ අපි සක්‍රීයව මැදිහත් වෙලා `do(Transport_Burden = Low)` කළොත්)"*
* එතකොට පද්ධතිය ගණනය කරලා කියනවා *"බස් එක දුන්නොත්, වෙන කිසිම දෙයක් වෙනස් නොවුණත්, ළමයා පාසල හැරයන අවදානම අනිවාර්යයෙන්ම 40%කින් අඩු වෙනවා"* කියලා.

මේ විදිහට **"කුමන උදව්වක් කළොත්ද ළමයාට වඩාත්ම හොඳ?" (What would help?)** කියලා හොයන්න පුළුවන් වෙන්නේ Bayesian Network එකකට විතරයි.

### හේතුව 3: දත්ත අඩුවෙන් තිබුණත් වැඩ කළ හැකි වීම (Handling Missing Data)

සාමාන්‍ය AI මොඩල් වලට දත්ත ටිකක් හරි අඩුවෙන් දුන්නොත් (උදා: ළමයාගේ ගෙදර පරිසරය ගැන ගුරුවරයා මුකුත් දන්නේ නැත්නම්), ඒ මොඩල් එකට හරියට උත්තරයක් දෙන්න බෑ. නැත්නම් මොකක් හරි බොරු දත්තයක් (Imputation) ඒ වෙනුවට දාගන්නවා.

නමුත් Bayesian Network එකක ගණිතය (Marginalization / Variable Elimination) හැදිලා තියෙන්නේම නොදන්නා දේවල් එක්ක වැඩ කරන්න. ළමයාගේ ගෙදර පරිසරය දන්නේ නැත්නම්, පද්ධතිය ඒ නොදන්නා සාධකයට තියෙන්න පුළුවන් හැම සම්පාවිතාවක්ම (පොහොසත් වෙන්නත් පුළුවන්, දුප්පත් වෙන්නත් පුළුවන්) එකට එකතු කරලා (Summing out), තියෙන දත්ත ටිකෙන් දෙන්න පුළුවන් නිවැරදිම අනුමානය ලබා දෙනවා.

---

### සාරාංශය

අපි මේ පද්ධතියට Bayesian Network එකක් තෝරාගත්තේ, අපිට ඕන වුණේ ළමයෙකුට **"අවදානම් ලේබලයක්"** ගහන පද්ධතියක් නෙවෙයි, ළමයෙකුගේ ප්‍රශ්නයක **"මුල හොයාගෙන, ඒකට දෙන්න පුළුවන් හොඳම විසඳුම කුමක්ද?"** කියලා ගුරුවරුන්ට පෙන්වන සදාචාරාත්මක පද්ධතියක් (Ethical Early-Support System) නිසාවෙනි.
